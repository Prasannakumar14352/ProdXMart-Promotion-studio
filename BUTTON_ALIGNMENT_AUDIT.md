# ProdXMart Promotion Studio — Button Alignment & Design System Audit

## 1. Button Inconsistencies Found Across Existing UI
1. **Height & Baseline Mismatch**: Only buttons explicitly given `.btn` or `.primary` received `height: 36px` in `css/components.css`. Standard `<button>` elements across `index.html`, `editor.js`, `agents.js`, `js/agent_views.js`, `js/phase4_studio.js`, `js/phase5_publishing.js`, and `js/phase6_analytics.js` rendered with unstyled browser defaults (~22px tall, inconsistent grey border), misaligning next to `36px` `<select>` / `<input>` / `.primary` controls.
2. **Inline Action Link Inconsistency**: Action links (`Export shop links`, `Save video`, `Product link`, `Download Manual Package (.zip)`, `Store`, `View URL`, `Export Excel`, `Export SKUs`) used plain underlined link styling alongside rectangular buttons instead of matching `.btn-sm` pill/button height and alignment.
3. **Top-Right Header Action Scope**: `#legacy-page-head` rendered `＋ Add product` and `Generate weekly batch` across every sub-route (`Settings`, `Integrations`, `Execution History`, `Sales Analytics`), even where neither action applies.
4. **Topbar Icon Visibility & Input Overlap**: `#mobile-menu-btn` was visible at `1440px` desktop next to `.sidebar-toggle`, and `.global-search input` lost `padding-left: 34px` to higher-specificity `input:not([type="checkbox"]):not([type="radio"])`, overlapping the search icon over placeholder text.
5. **Approval Actions Clarity**: Social approval cards offered `Save Edit`, `Regenerate`, `Approve`, `Reject`, `Schedule` — missing a distinct `Request Changes` action and lacking accessible `title` tooltips explaining disabled reasons (`QA required`, `Global stop active`, `Publish first`).
6. **Raw Unicode Symbols on Controls**: Mixed `＋`, `×`, `←`, `→`, `✓`, `✗` across buttons instead of clean Lucide icons / unified spacing.
